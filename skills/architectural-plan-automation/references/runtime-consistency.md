# 平面运行一致性与最终项目闭环

本流程覆盖现有启动、生成排版、最终重开三个位置，不另建一套成图流水线。最新用户要求覆盖历史要求；适用范围为建筑平面出图质量。

## 入口与参数

- 启动核实际模块SHA、当前规则、模板、打印资源和项目源DWG，断点同时绑定这些文件及执行脚本指纹。
- `assets/annotation-template/standard.json` 为三套文字参数来源，`typography.tsv` 是由同步脚本派生的原生执行文件。原生写入和独立Python复核必须核同一来源SHA；文件缺失、版本不同不能回退硬编码旧值。
- FY_HZ：tssdeng.shx＋hztxt.shx，纸面4.0、宽0.7；_TCH_DIM：simplex.shx＋gbcbig.shx，纸面2.8、宽1；_TCH_WINDOW：simplex.shx＋gbcbig.shx，纸面3.0、宽0.65、样式固定高度3.0。模型有效高度按实际单位及比例换算。专用图名、轴号等按自己的现行用途规则。
- 原图同名样式不得覆盖。既核样式定义，也核最终对象的字体文件、有效字高、宽度及行内覆盖；不采信旧回执自报的expectedHeight或verified标记代替现行参数。
- 缺字体监听仅服务已核身份的自有宿主，按作业时限和无进度期限结束；不能用“第16次已响应”认定字体已解决。未解析的实际字体依赖须记入清单。

## 生成与排版

- 在生成前冻结每层应有轴位、编号、分侧显隐。源逻辑轴、有效测站与圈线分别管理，模板原生候选验证成功后替换。失败保留合法表达并记录，不能删圈后仅剩轴线。
- A28只允许直引或一次转折后斜线直接接圆。最小可行偏移由圈径和斜线几何确定；不能因旧100～200偏移试排失败，继续拼短直尾。应有端记录随DWG保存，重开逐端匹配；旧图没有原应有记录时必须说明核验边界，不能凭现存圈证明从未漏圈。
- 表格按完整对象归属和完整边界入幅。支持可明确识别的原生表、完整网格块表和具有明确成员的既有CAD组；复杂散线表归属不确定时保留并列明，不能按每个单元格离哪层近而拆散。完全落在打印窗口外的已登记表格也属于缺失。逐成员核关闭层、不打印层及本幅视口冻结，不能仅以包围框入幅判通过。纸空间图签另核实际文字边界与打印纸边；字体参数正确不能代替裁切检查，无法在保持规则参数及模板结构的前提下安全调整时列明具体对象路径和越界范围。
- 有SU或文件门窗资料时，按源指纹、资料指纹、逐樘对象及明确定位依据采用宽高，联动平面几何、公开原生属性、编号及受影响测站。多源冲突无明确依据时逐樘列项。含几何采用的任务必须经过生成/修订全链，不能只跑模板样式终核。
- 主体／围墙按逐墙用途分离，同一连通组件内也需剔除围墙对主体主尺寸、轴号和四框的影响。围墙独立长度及围墙门号另核。明确围墙用途与主体层高写入流程共用，不能终核又把围墙套成主体层高。
- 保留家具原块和嵌套，只改已确认对象用途图层；每幅四道Defpoints实体辅助框模型可见、灰色虚线、不打印。旧后处理不得重新炸家具或删辅助框。

## 最终重开

1. 保存并独立重开同版DWG。逐层核墙高、三套文字实际使用参数、应有轴圈与直接接圆、尺寸测点测值、门窗资料采用、表格完整性、家具和四框。
2. 重新枚举最终模型、块及相关布局中的标注。核室内尺寸与房间面积零残留，包含合图或旧模块后加的对象。室外、开敞庭院、主体建筑面积表与房间面积区分；只对明确房间净域内的用途自动清理，未知归属列清单，不凭四向有墙推定。家具保护约束写入，不免除只读检查；可读标注继续核，未读子域和不可读容器按实例记录覆盖范围。枚举过根对象或残留计数为零，均不能代替未知范围的核验。
3. 风险字符只检项目实际出现的单位符号等，读实际SHX轮廓并与缺字占位轮廓比对。字库存在或字体名正确不等于字符能打印；未测到轮廓不得判通过。对已证实缺字的建筑面积说明，仅无字段、无关联的普通文字可将㎡等价改写为实际字体已验证可印的m²；保存重开逐字核其余正文和数字不变。关联或未知表达保留并列项，不自行改面积数值。
4. 局部失败采用至多两种不同策略；同一对象、同一候选不重复试排。失败回滚并继续其他项。改动了几何或字形的部分重新核对应图幅，最后整套实打一次；确需返修的重印据实计数。
5. 每个原生阶段核自有宿主身份、正常退出和隔离终态。业务回执成功不能掩盖异常退出；异常尝试保留并按既有次数上限重试，断点复用亦核终态。
6. 发布DWG、最终读回、实际打印和未解决清单绑定同一SHA。`processingCompleted`、`delivered`、`checkedRulesPassed`、`coverageComplete`与`allRulesPassed`分别记录；规则已加载、PDF已生成、网站任务已完成均不能等同全部规则通过。

## 证据与回归

使用已有报告，不以新规则目录代替逐对象验收。重点读取`template-typography-readback.json`、`plan-final-omissions-readback.json`、`plan-risk-glyph-readback.json`、`plan-font-dependencies-readback.json`、`plan-final-rule-evidence.json`、`publication-quality-status.json`、轴号应有端记录、`plan-table-readback.json`、门窗资料读回、墙高读回和最终打印记录。实际报告名以当前代码输出为准。

发布新版前至少验证一个已出错项目、一个其他楼层或户型案例；分别记录首轮失败、返修及最终结果，比较成图时间、重开次数和打印次数。没有新版本实跑证据的规则保留“未验证/待接入”，不批量改成通过。网站工作机另核实际部署模块和资源SHA，本机通过不能代替远端已更新。

# 平面成图验收清单

最终字体验收使用独立重开后的 `final-typography-readback.json`，覆盖整份 DWG 的适用可见标注；逐对象及尺寸逐段核实际样式引用、字体文件、有效高度、实例比例和行内覆盖。同名样式正确、原样保留或局部通过均不能代替这一终核。报告必须绑定最终 DWG 指纹，未知用途与不支持的关联表达列未解决，不混入通过。整图生成发布入口检查该报告与遗留清单的一致性。图名、面积、标高、轴号、图签及测绘标注不套普通文字规则，按自身适用项核验；分类本身不代表专用规则已通过。

对照[详细规则](rules.md)和[项目参数](project-parameters.md)，以本轮输入和已确认要求建立应有清单。分别保存原生对象读回、编辑试验及原生图面证据。逐项判定后再给整轮结论。

## 1. 确定验收范围

| 任务 | 必查范围 | 可交付结论 |
| --- | --- | --- |
| 只读复核 | 当前图中用户指定的楼层、侧别及模块；如为整图复核，覆盖每幅平面和各适用模块。以只读方式获取证据；需修改或试拖的项目记为未验证。 | 复核范围、实测项、缺漏冲突及证据不足项。 |
| 局部修订 | 指定对象、与其关联的测点和标注，以及应受保护的周边、其他楼层和共享资源。对照修订前后的图元与显示，复核已有待办。 | 新 DWG、逐项修订结果、受影响范围和未关闭事项。 |
| 整图生成与施工图深化 | 每幅平面和四侧逐项建账，核对构件保留、应生成内容及适用模块。归属不明的局部图独立列项。 | 经独立重开及同版图面核验的正式版 DWG。有未关闭的平面问题时按 P06 附同版遗留清单。 |

无人值守正式出图逐层执行建筑平面图面质量验收。保留露台、檐口和现有出入口的源方案表达，重开核对其可见几何及适用的定位和标注。逐项核样式、字体、字高、数量、道次、测站、图层和实际纸面净空。保存独立重开及同版图面核验后，按 P06 交付正式版 DWG 并附实际遗留事项。

开始前记录项目、任务模式、源 DWG 版本或 SHA256、参考图、规则版本、实际使用的项目参数、单位、出图比例、楼层、范围及输出文件名。使用了插件时另记录安装版本或实际加载模块的标识。沿用未关闭事项，区分本轮改动、继承问题、项目特例和暂停项。副本通过前保留原方案、参考图和用户手改原件。

## 2. 建立应有和实有清单

按「楼层或图幅 → 侧别、房间或构件 → 测站或对象」登记。应有项来自本轮输入、用户确认及适用规则。实有项来自独立读取的成果 DWG，含模型空间直接对象、普通块及相关嵌套成员。逐项匹配后查缺漏、重复、误归属和越界变更。 对尺寸逐段登记两端的源对象与用途，量取实际测值并核显示值、比例、文字覆盖和舍入。D24 含洞口的相关开间逐个核从轴到轴的分段闭合。等厚共线墙的无定位拼接点和真实近轴洞口边分别检查。句柄用来定位本图；跨图匹配结合楼层、构件关系、变换和实际几何。

| 记录字段 | 填写内容 |
| --- | --- |
| 位置与关联 | 项目、楼层或图幅、侧别或部位、构件名称、源与成果对象标识或可复核测点。 |
| 规则与应有 | 规则编号或用户确认出处，应有对象、类型、测站、值、有效样式、覆盖范围或保留要求。 |
| 实测与差异 | 实有对象类型和参数、测点、读数、夹点或有效显示；列出与应有值的具体差异。 |
| 状态与处置 | 通过、待确认、待修复、修复待验、未验证、用户暂停或不适用。未通过项另记原因、保留方式、影响和下一步。 |
| 证据 | 源图或确认参数、保存独立重开后的原生读回记录、对应图面局部。实际做了编辑试验时记变动、还原和复核。 |

例如，一根偏心柱轴在本侧隐藏轴圈，账内仍应分别记录独立轴线起止、隐藏的圈及专用引线，以及第二道尺寸保留的柱墙轴测站。只核对可见轴圈数量会漏验尺寸测站。

### 逐层必验项

#### 主平面验收与交付

发布前对照源台账独立重开核零残留：原房间面积及上标、旧轴线及对应旧圈线、孤立折引线。同轴同号逐层核实，第三道按图幅、侧别、用途和测站查重，房名等按用途核实际层、色、字体和字高。发现已确认错号、重复链、残线或错层先修正，再从同一版实打。

1. **主平面图面完整**。按本项目实际图幅核构件、轴网、必要尺寸、编号、标高、房名和适用说明。样式、字体、字高、数量、道次、测站、图层按现行规则逐项核定。所有旧房间面积及其上标已删除，新房间面积为零。
2. **重开结果正确**。独立重开与源图对账，核实际对象、测点、测值、房间面积与旧轴线退出记录及有据省标。原尺寸的内部去向记录可继续跟踪。实际必要尺寸的漏标或错标复试并逐项记录结论。
3. **交付文件可用**。核图签、图号、比例、线宽、裁切和文字。允许已验证等效的项目打印样式。需要 PDF 时，从同一交付 DWG 输出并逐页核图。

将 `plan-rule-ledger.json` 中每个 pending／failed 的 `drawingChecks` 与实际遗留问题逐项对账。`inventory-binding` 表示程序检查引用没有登记的应有项，属于执行覆盖缺陷，应修复登记或作用范围；不要让用户补设计值来消除它。尺寸避让的 `collisionAdjusted` 不等于默认界线长度通过，须同时核其冲突依据、各段净空和可见界线。

查看 `plan-delivery-review.json` 的 `gates` 和 `blockingLocations` 作为返工与复验依据。同层同一实际部位可合并。尺寸、轴号、轴线、门窗编号等制图问题逐项复试。重复复验仍无法解决的，记录规则、楼层、可定位部位、原因、已试处理和实际保留状态，继续其他独立项。有关严格规则仍记未通过或未验证。施工依据和构造设计随项目另核。

- [ ] **层高及实际墙高（B04、SE02）**　用 `storey-wall-height-readback.json` 逐层对照层高依据、B04 默认值和累计楼面值。逐墙核最终 DWG 原生高度、原底标高、原墙厚与关联门窗。分别记录源图冲突、墙高写入失败和楼面符号缺项。
- [ ] **墙高（B04）**　逐层核本层与上层楼面标高的差值及各墙的实际高度。缺标高且无法查得实际高差或已确认层高时，核该层各墙为 3.3 m，并记录采用默认值的依据和楼层。核已确认楼面标高保留。
- [ ] **最终图面**　检查每幅整体及影响部位的实际原生渲染，核尺度、字形、圈线、文字、引线、尺寸与构件的重叠，检查过长或裁切及已取消的遮罩。标注位置确实无解时保留必要对象，登记待调整位置与影响。用过的临时见证标记应留在核验副本中。

## 4. 判定、留证与交付

1. **独立重开读回。** 生成或修订后关闭成果并独立重开，以最终 DWG 回读。采集真实对象类型、测点、参数、夹点、编号、图层及实际生效样式。对要求原生编辑的对象，按已授权方法用验证副本测试，记录整链或共享节点响应及还原。代理预览仅提供图面线索。环境不支持某项读回或试验时，将该项标为未验证。
2. **分类处理异常。** 缺项按参数缺失、规则未定、输入冲突、接口未支持或布局待调整分类。记实际值与应有值、出处、影响和下一步。对未知单轴、未知门型或局部构造，保留可靠原表达，继续验收独立可处理项。按项目明确要求在图面标注“待确认”或“待调整”。
3. **按证据判定。** 通过项需同时符合应有要求和对应证据。对象总数、构件外观、前后哈希一致、成功保存或编译成功各自只证明对应事实。应有项缺失、真实性或测点不符合时列待修复。修订已实施但缺重开或图面证据时列修复待验。无法验证的项给出已做的检查。暂停和不适用项附依据，保留继承未关闭事项。
4. **分别登记状态。** 规则注明确认依据及日期；项目 DWG 注明文件、验收范围和实测结论；源码接入注明实际入口与回归覆盖；安装包验收注明版本、真实安装或版本实物的验证范围。接口试验和个案成功单独留证。若运行隔离 CAD 宿主，记录实际正常退出及本轮自有暂存处理。
5. **交付可复核成果。** 核交付文件存在、可打开，文件名能区分项目、修订版本及正式状态。整图生成和施工图深化按 P06 交付正式版 DWG。有遗留时附同版清单。用户另行要求 PDF 时从同一 DWG 输出。只读复核交结论与问题清单，局部修订按指定范围交付。

跨项目验证要实跑不同源图，核对实际 DWG、逐层核验记录与同版遗留清单。`tools/verify_cross_project_release.py` 逐项核对严格验收状态及交付结果。验证局部留项仍能交付时用 `--allow-pending-suite` 核对机制，单独记录全项规则通过的数量。整图 Generate 当前支持 1:100、毫米模型。其他比例单位、旋转镜像、多栋图及修订后的适用性，以各自实测为准。

## 模板来源和打印专项复核

- 尺寸、轴号来源为随包已核SHA模板，逐对象绑定源样件句柄；旧项目同名定义不覆盖，基础与派生样式分别比对。
- 按[模板强规则](template-standard.md)逐用途核图层、A3/A4或A1线宽；同色7不同线宽、色254不同灰度分别核，不能只核ACI。
- 核实际CTB/PC3及PDF字体转几何；未绑定样式或字体替代不能记为通过。缺项定位列清单，继续独立项。
